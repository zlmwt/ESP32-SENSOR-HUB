ESP32 Monitoring and Logging Website created using Firebase for server backend, Vite for website frontend, and Vercel for deployment and hosting

Sensors Used:
1. DS18B20 Temperature Sensor
2. MQ2 Gas Sensor

Features:
1. Start/Stop Logging
2. Logging Interval Setting
3. Graph Comparing DS18B20 and MQ2 Sensor Data
4. Historical Table Showing the Last 10 Logged Data
5. Data Analysis and Categorisation (Normal, Low Risk, Medium Risk, Dangerous)
6. Data Simulation To Test Out the Features

Hopefully you all liked it :D
